# 企业级供应商付款批次治理

[知华科技](https://www.zhuatech.cn/)（上海如静知华信息科技有限公司）将应付核销、资金计划、审批和银行支付前控制串成可审计闭环。

## 关键能力
- 三单匹配、重复发票、供应商银行账户及制裁筛查联合校验。
- 会计期间、资金计划、金额审批矩阵和制单/审批职责分离。
- 支付文件签名、批次幂等键、大额/紧急付款资金负责人复核。
- 支付依据留痕，并生成银行回执和总账对账动作。

接口：`POST /api/enterprise/erp/vendor-payment-batch`，输出 `RELEASE / REVIEW / BLOCKED` 及动态审批路径。
